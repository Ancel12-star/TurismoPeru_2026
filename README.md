# Proyecto Base de Datos - Turismo Perú 2026

## Descripción General
Este proyecto tiene como objetivo gestionar los datos del sistema Turismo Perú, integrando herramientas de desarrollo como Python, Flask, SQL Server, Git y Visual Studio Code.

## Fases del Proyecto
- Configuración de entorno y dependencias.
- Desarrollo backend y frontend (MVC, conexión a base de datos y procedimientos almacenados).
- Documentación y versionamiento de código.

## Competencias a Desarrollar
- Manejo de entornos de desarrollo con Visual Studio Code y entornos virtuales.
- Versionamiento de proyectos y gestión de ramas mediante Git Bash.
- Aplicación de estructuras en Python (Flask) y bases de datos relacionales (SQL Server).
